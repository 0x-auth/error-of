# Exploration code

Kept as history. The finished versions are `error_of/walk.py`,
`examples/reconstruct/fib.py` and `examples/organism/organism.py`.
Run any of these with `python3 <file>` from this folder.

| file | what it shows |
|---|---|
| `stern_brocot_walker.py` | a probabilistic walker on the tree of all fractions |
| `spacetime_walker.py` | 1024 cells, dx = t - 1/t, dt = t + 1/t; t sets the light cone |
| `frozen_model.py` | input as a selector: works only for what the model holds |
| `frozen_model_v2.py` | input carries the rule: 18! from a 10-number vector |
| `walker_input.py` | a fixed 22-dimension input; cycle and precision errors |
| `program_model.py` | a sentence becomes a program or "no P" (meaning of life) |
| `row_model.py` | input as rows; first 20 twin primes |
| `pc_model.py` | a complete machine: memory, jumps, read, write; palindromes in "madam" |
| `programs.py` | every earlier problem on that one unchanged machine |
| `route.py` | shortest route A to Z over eight points, checked against all orders |
| `loop.py`, `demo_fib.py` | the first error-driven loop (X before error-of ran it) |
